## 🖨️ How to Generate PDF Resume
1. Double-click to open [`Abdul_Muqtadir_Resume.html`](Abdul_Muqtadir_Resume.html) in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox).
2. Click the blue **"Print / Save as PDF"** button at the top (or press `Ctrl + P`).
3. Under Destination, choose **"Save as PDF"**.
4. Set margins to **"Default"** or **"None"** and check **"Background graphics"**.
5. Save as `Abdul_Muqtadir_Resume.pdf`.
